دوره اول · HTML

آموزش HTML از پایه

درس‌ها را به‌ترتیب مطالعه کن و مثال‌ها را در محیط تمرین امتحان کن.

01
HTML · درس ۱

ساختار یک صفحه HTML

HTML زبان نشانه‌گذاری صفحات وب است. این زبان مشخص می‌کند عنوان‌ها، متن‌ها و سایر محتواها چگونه در صفحه سازمان‌دهی شوند. 

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا!</h1>
  <p>اولین صفحه وب من</p>
</body>
</html>

توضیح: محتوای قابل مشاهده صفحه داخل body قرار می‌گیرد.

تمرین: متن h1 و پاراگراف را تغییر بده.

02
HTML · درس ۲

عنوان‌ها و پاراگراف‌ها

تگ‌های h1 تا h6 برای عنوان‌ها استفاده می‌شوند. تگ p هم یک پاراگراف متنی ایجاد می‌کند. 

<h1>عنوان اصلی</h1>
<h2>عنوان فرعی</h2>
<h3>عنوان کوچک‌تر</h3>

<p>این یک پاراگراف است.</p>

تمرین: یک عنوان h2 و دو پاراگراف ایجاد کن.

03
HTML · درس ۳

لینک‌ها و تصاویر

تگ a لینک می‌سازد. ویژگی href مقصد لینک را مشخص می‌کند. برای نمایش تصویر از img و ویژگی src استفاده می‌شود. 

<a href="https://example.com">
  مشاهده وب‌سایت
</a>

<img src="image.jpg"
     alt="توضیح تصویر">

نکته: ویژگی alt توضیح متنی تصویر است.

تمرین: یک لینک و یک تصویر به صفحه اضافه کن.

04
HTML · درس ۴

فهرست‌ها

از ul برای فهرست نشانه‌دار و از ol برای فهرست شماره‌دار استفاده می‌کنیم. هر مورد داخل li قرار می‌گیرد. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>درس اول</li>
  <li>درس دوم</li>
</ol>

تمرین: فهرستی از پنج فناوری مورد علاقه‌ات بساز.

05
HTML · درس ۵

فرم‌ها و ورودی‌ها

فرم‌ها برای دریافت اطلاعات کاربر به کار می‌روند. label عنوان ورودی را مشخص می‌کند و input داده را دریافت می‌کند. 

<form>
  <label for="username">نام</label>
  <input id="username"
         name="username" type="text">

  <label for="email">ایمیل</label>
  <input id="email"
         name="email" type="email">

  <button type="submit">ارسال</button>
</form>

تمرین: یک ورودی برای دریافت شماره تلفن اضافه کن.

دوره دوم · CSS

آموزش CSS از پایه

از رنگ و متن شروع کن و سپس چیدمان و طراحی واکنش‌گرا را یاد بگیر.

01
CSS · درس ۱

رنگ و اندازه متن

CSS ظاهر عناصر HTML را کنترل می‌کند. ویژگی color رنگ متن و font-size اندازه نوشته را مشخص می‌کند. 

h1 {
  color: royalblue;
  font-size: 32px;
}

p {
  color: #334155;
}

تمرین: رنگ عنوان را سبز و اندازه آن را 36 پیکسل کن.

رفتن به محیط تمرین ←
02
CSS · درس ۲

پس‌زمینه و کلاس‌ها

با کلاس‌ها می‌توانیم به عناصر انتخاب‌شده استایل بدهیم. نام کلاس در CSS با نقطه شروع می‌شود. 

.highlight {
  color: darkorange;
  background-color: #fff3cd;
  font-weight: bold;
}

برای استفاده از این کلاس در HTML بنویس:

<p class="highlight">
  این متن برجسته است.
</p>

تمرین: کلاسی به نام box بساز و رنگ پس‌زمینه آن را تغییر بده.

رفتن به محیط تمرین ←
03
CSS · درس ۳

فاصله‌ها و کادرها

margin فاصله بیرونی، padding فاصله داخلی و border کادر دور عنصر را تنظیم می‌کند. 

.card {
  margin: 20px;
  padding: 16px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
}

تمرین: یک کارت با گوشه‌های گرد و فاصله داخلی بساز.

رفتن به محیط تمرین ←
04
CSS · درس ۴

چیدمان با Flexbox

Flexbox کمک می‌کند عناصر را در ردیف یا ستون بچینیم و فاصله و تراز آن‌ها را کنترل کنیم. 

.cards {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 16px;
}

تمرین: سه کارت بساز و با Flexbox کنار هم قرار بده.

رفتن به محیط تمرین ←
05
CSS · درس ۵

طراحی واکنش‌گرا

با media query می‌توانیم ظاهر صفحه را برای نمایشگرهای کوچک تغییر دهیم. 

.cards {
  display: flex;
  gap: 16px;
}

@media (max-width: 600px) {
  .cards {
    flex-direction: column;
  }
}

تمرین: اندازه breakpoint را تغییر بده و صفحه را در موبایل بررسی کن.
