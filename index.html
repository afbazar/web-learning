دوره اول

آموزش HTML از پایه

HTML ساختار و محتوای صفحات وب را مشخص می‌کند.

درس ۱

HTML چیست؟

HTML زبان نشانه‌گذاری برای تعریف ساختار صفحات وب است.

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا</h1>
  <p>اولین صفحه من</p>
</body>
</html>

تمرین: عنوان صفحه و متن پاراگراف را تغییر بده.

درس ۲

عنوان‌ها و پاراگراف‌ها

از تگ‌های h1 تا h6 برای عنوان‌ها و از p برای پاراگراف استفاده می‌کنیم.

<h1>عنوان اصلی</h1>
<h2>عنوان فرعی</h2>
<p>این یک پاراگراف است.</p>
<p>این هم پاراگراف دوم است.</p>

تمرین: یک عنوان و دو پاراگراف درباره خودت بنویس.

درس ۳

لینک‌ها

تگ a برای پیوند دادن صفحات یا سایت‌ها استفاده می‌شود.

<a href="https://example.com">
  باز کردن سایت نمونه
</a>

<a href="#contact">
  رفتن به بخش تماس
</a>

تمرین: یک لینک به سایت دلخواهت اضافه کن.

درس ۴

تصاویر و فهرست‌ها

تگ img برای تصاویر و تگ‌های ul، ol و li برای فهرست‌ها هستند.

<img src="photo.jpg" alt="توضیح تصویر">

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

تمرین: فهرستی از سه مهارت موردعلاقه‌ات بساز.

درس ۵

فرم‌های HTML

فرم‌ها برای دریافت اطلاعات از کاربران استفاده می‌شوند.

<form>
  <label for="name">نام:</label>
  <input id="name" name="name" type="text">

  <button type="submit">
    ارسال
  </button>
</form>

تمرین: یک فرم ساده با فیلد نام بساز.

بعد از یادگیری ساختار HTML، سراغ طراحی ظاهری با CSS برو.

دوره دوم

آموزش CSS از پایه

CSS ظاهر، رنگ‌بندی و چیدمان صفحات وب را کنترل می‌کند.

درس ۱

CSS چیست؟

CSS با انتخاب عناصر HTML و تعریف ویژگی‌ها، ظاهر آن‌ها را تغییر می‌دهد.

p {
  color: blue;
  font-size: 18px;
}

h1 {
  color: darkgreen;
}

تمرین: رنگ متن پاراگراف را تغییر بده.

درس ۲

رنگ و پس‌زمینه

با color رنگ متن و با background-color رنگ پس‌زمینه را تنظیم می‌کنیم.

body {
  background-color: #f1f5f9;
}

h1 {
  color: #2563eb;
}

.card {
  background-color: white;
}

تمرین: پس‌زمینه یک کارت را تغییر بده.

درس ۳

فاصله‌ها و کادرها

padding فاصله داخلی و margin فاصله بیرونی عنصر را تنظیم می‌کند.

.card {
  padding: 24px;
  margin: 16px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
}

تمرین: گوشه‌های کارت را گردتر کن.

درس ۴

کلاس‌ها و شناسه‌ها

برای انتخاب عناصر می‌توان از class با نقطه و از id با علامت # استفاده کرد.

<p class="note">متن ویژه</p>
<h2 id="title">عنوان</h2>

.note {
  color: purple;
}

#title {
  font-size: 30px;
}

تمرین: یک کلاس جدید تعریف و روی یک عنصر اعمال کن.

درس ۵

چیدمان واکنش‌گرا

با Flexbox و Media Query می‌توان چیدمان را با اندازه صفحه هماهنگ کرد.

.cards {
  display: flex;
  gap: 16px;
  flex-wrap: wrap;
}

.card {
  flex: 1 1 220px;
}

@media (max-width: 600px) {
  .cards {
    flex-direction: column;
  }
}

تمرین: چیدمان را در صفحه‌های کوچک آزمایش کن.

حالا مثال‌های خودت را در محیط تمرین اجرا کن.
