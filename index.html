01
HTML

HTML چیست؟

HTML زبان نشانه‌گذاری صفحات وب است. با استفاده از تگ‌ها، ساختار محتوای صفحه را تعریف می‌کنیم. 

<h1>سلام دنیا!</h1>
<p>این اولین صفحه من است.</p>

تگ h1 برای عنوان اصلی و تگ p برای یک پاراگراف استفاده می‌شود.

02
CSS

CSS چیست؟

CSS ظاهر عناصر HTML را کنترل می‌کند؛ از رنگ و اندازه نوشته‌ها تا چیدمان کامل صفحه. 

h1 {
  color: royalblue;
  font-size: 32px;
}

این قانون رنگ عنوان‌ها را آبی می‌کند و اندازه نوشته را افزایش می‌دهد.

03
JavaScript

JavaScript چیست؟

JavaScript به صفحه وب امکان واکنش به کلیک کاربر، بررسی داده‌ها و تغییر محتوا را می‌دهد. 

const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("سلام برنامه‌نویس!");
});

با کلیک روی دکمه، یک پیام به کاربر نمایش داده می‌شود.

04
Python و Django

Django چیست؟

Django چارچوبی برای ساخت بک‌اند با Python است. برای یادگیری آن بهتر است ابتدا مبانی Python را بلد باشی. 

from django.http import HttpResponse

def home(request):
    return HttpResponse("سلام از Django!")

این نمونه برای اجرا به یک پروژه Django نیاز دارد؛ GitHub Pages به‌تنهایی قادر به اجرای آن نیست.
