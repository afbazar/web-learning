درس‌های رایگان

مسیر یادگیری HTML و CSS

درس‌ها را به ترتیب بخوان، مثال‌ها را بررسی کن و کدها را در محیط تمرین اجرا کن.

01
HTML · درس ۱

ساختار یک صفحه HTML

HTML ساختار محتوای صفحه را مشخص می‌کند. یک سند استاندارد شامل بخش‌های head و body است.

<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحه من</title>
</head>
<body>
  <h1>سلام دنیا!</h1>
  <p>اولین صفحه وب من</p>
</body>
</html>

تمرین: متن عنوان و پاراگراف را تغییر بده.

02
HTML · درس ۲

عنوان‌ها و پاراگراف‌ها

برای عنوان‌ها از تگ‌های h1 تا h6 و برای پاراگراف‌ها از تگ p استفاده می‌کنیم.

<h1>آموزش برنامه‌نویسی</h1>
<h2>آموزش HTML</h2>
<p>در این درس با HTML آشنا می‌شویم.</p>

تمرین: یک عنوان h2 و یک پاراگراف جدید اضافه کن.

رفتن به محیط تمرین ←
03
HTML · درس ۳

لینک‌ها و تصاویر

تگ a برای ساخت لینک و تگ img برای نمایش تصویر به کار می‌رود. ویژگی href مقصد لینک و ویژگی src آدرس تصویر را مشخص می‌کند.

<a href="https://example.com">
  مشاهده وب‌سایت
</a>

<img src="image.jpg" alt="توضیح تصویر">

نکته: ویژگی alt توضیح متنی تصویر را برای دسترس‌پذیری فراهم می‌کند.

تمرین: یک لینک به سایت دلخواهت اضافه کن.

رفتن به محیط تمرین ←
04
HTML · درس ۴

فهرست‌ها

از ul برای فهرست نشانه‌دار و از ol برای فهرست شماره‌دار استفاده می‌کنیم. هر مورد داخل li قرار می‌گیرد.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>یادگیری HTML</li>
  <li>یادگیری CSS</li>
</ol>

تمرین: فهرستی از سه فناوری مورد علاقه‌ات بساز.

رفتن به محیط تمرین ←
05
HTML · درس ۵

فرم‌ها و ورودی‌ها

فرم‌ها برای دریافت اطلاعات از کاربر استفاده می‌شوند. label عنوان ورودی و input محل وارد کردن اطلاعات است.

<form>
  <label for="username">نام کاربری</label>
  <input id="username" name="username" type="text">

  <label for="email">ایمیل</label>
  <input id="email" name="email" type="email">

  <button type="submit">ارسال</button>
</form>

تمرین: یک ورودی برای دریافت نام کاربر اضافه کن.

رفتن به محیط تمرین ←
06
CSS · درس ۱

رنگ، متن و پس‌زمینه

CSS ظاهر عناصر HTML را کنترل می‌کند. ویژگی color رنگ متن و background-color رنگ پس‌زمینه را تعیین می‌کند.

h1 {
  color: royalblue;
  font-size: 32px;
}

p {
  color: #334155;
  background-color: #f1f5f9;
}

تمرین: رنگ عنوان را سبز و اندازه آن را 36 پیکسل کن.

رفتن به محیط تمرین ←
07
CSS · درس ۲

کلاس‌ها و انتخابگرها

با ویژگی class می‌توانیم عناصر مختلف را برای استایل‌دهی انتخاب کنیم. نام کلاس در CSS با نقطه شروع می‌شود.

<p class="highlight">
  این متن مهم است.
</p>

/* در CSS */
.highlight {
  color: darkorange;
  font-weight: bold;
}

تمرین: کلاسی به نام box بساز و به آن پس‌زمینه و فاصله داخلی بده.

رفتن به محیط تمرین ←
08
CSS · درس ۳

فاصله‌ها و کادرها

margin فاصله بیرونی، padding فاصله داخلی و border خط دور عنصر را مشخص می‌کند.

.card {
  margin: 20px;
  padding: 16px;
  border: 1px solid #cbd5e1;
  border-radius: 12px;
}

تمرین: یک کارت با گوشه‌های گرد و فاصله داخلی مناسب طراحی کن.

رفتن به محیط تمرین ←
09
CSS · درس ۴

چیدمان با Flexbox

Flexbox برای چیدن عناصر در ردیف یا ستون و تنظیم فاصله و تراز آن‌ها استفاده می‌شود.

.cards {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 16px;
}

تمرین: سه کارت بساز و با Flexbox کنار هم قرارشان بده.

رفتن به محیط تمرین ←
10
CSS · درس ۵

طراحی واکنش‌گرا

با media query می‌توانیم ظاهر صفحه را برای نمایشگرهای کوچک تغییر دهیم.

.cards {
  display: flex;
  gap: 16px;
}

@media (max-width: 600px) {
  .cards {
    flex-direction: column;
  }
}

تمرین: مقدار breakpoint را تغییر بده و رفتار چیدمان را بررسی کن.
